## AI 교차 검증 체크리스트

> PRD 완성 후 AI 인스턴스에 각 섹션을 검증하도록 요청한다

- [ ] **PM 관점**: 사용자 문제가 명확하고 검증 가능한가?
- [ ] **전략 관점**: 비즈니스 목표와 정렬되어 있는가?
- [ ] **엔지니어 관점**: 기술적으로 실현 가능하고 모호함이 없는가?
- [ ] **디자이너 관점**: UX 흐름이 논리적이고 사용자 친화적인가?
- [ ] **스코프 체크**: Gold plating(필요 이상의 기능)이 포함되지 않았는가?
- [ ] **가설 체크**: 검증되지 않은 가정에 의존하고 있지 않은가?
- [ ] **측정 체크**: 모든 목표가 측정 가능한 지표와 연결되어 있는가?
