## Claude 데스크톱 앱 탐색: Chat, Cowork, Code

Claude 데스크톱 앱은 Claude와 작업하는 세 가지 방법을 제공합니다: 빠른 질문부터 복잡한 연구, 소프트웨어 구축까지 가능한 Chat(채팅), Cowork(협업), Code(코드) 모드입니다.

Chat은 여러분이 claude.ai에서 알고 있던 바로 그 Claude입니다. 컴퓨터에서 기본으로 실행되기 때문에 얻게 되는 빠른 입력, 스크린샷, 받아쓰기, 커넥터 등의 기능이 추가되었습니다. Cowork는 Claude가 더 많은 일을 할 수 있는 범위와 공간을 제공합니다. 이 넓은 범위를 통해 더 철저한 리서치와 분석을 수행하고, 더 복잡한 문서와 결과물을 만들어낼 수 있습니다. Code는 코드 작성 및 테스트부터 배포까지 소프트웨어 구축을 위한 모드입니다.

Cowork와 Code는 같은 엔진에서 실행됩니다. 두 모드 모두 내부적으로는 여러분의 컴퓨터 로컬에서 실행되고, 독립적인 작업이 가능하며, 하위 에이전트(sub-agents)를 가동해 긴 작업을 지속할 수 있는 Claude Code를 기반으로 합니다. 이를 통해 Claude는 리서치 및 글쓰기나 소프트웨어 개발 같은 큰 규모의 작업을 스스로 처리할 수 있습니다.

각 모드는 수행하는 작업에 맞춰 설계되어 중요한 것을 보여주고, 필요한 곳에서 통제권을 부여합니다.

## Chat

Chat은 질문하고, 아이디어를 내고, 초안을 작성하거나 문제를 주고받으며 풀어나갈 때 뛰어납니다.

claude.ai를 사용해 보셨다면 작동 방식은 동일하지만, 컴퓨터에 설치됨으로써 얻을 수 있는 몇 가지 기능이 있습니다:

- **빠른 입력 (Quick entry).** Mac의 Option 키를 두 번 누르면 작업 중인 화면 위에 Claude를 띄울 수 있습니다. 앱 간 전환 시에도 항상 최상단에 유지되는 작은 창으로 응답합니다. 질문을 하기 위해 하던 일을 멈추고 떠날 필요가 없습니다.
- **스크린샷 및 창 공유 (Screenshots and window sharing).** 스크린샷을 캡처하거나 창을 공유하여 Claude가 여러분이 보고 있는 화면을 정확히 보게 할 수 있습니다. 화면을 설명하는 것보다 빠르고 더 정확합니다. (Mac)
- **받아쓰기 (Dictation).** 타이핑하는 대신 말로 문제를 풀어나가 보세요. 소리 내서 생각을 정리하거나, 키보드에서 멀어져 있을 때, 또는 글보다 말로 설명하는 것이 더 빠른 작업을 할 때 유용합니다. (Mac)
- **데스크톱 커넥터 (Desktop connectors).** 커넥터를 통해 로컬 도구와 서비스를 연결하여 Claude가 컴퓨터의 다른 도구들과 함께 일할 수 있게 합니다.

**이럴 때 사용해 보세요:**

- 낯선 대시보드를 보고 있을 때. Option 키를 두 번 누르고, 마우스로 대시보드 창을 드래그하여 스크린샷을 찍은 뒤, "이 지표들이 무슨 뜻이야?"라고 물어보세요. 대시보드를 띄워놓은 채로 오버레이 창에서 Claude의 답변을 볼 수 있습니다.
- 회의 중간에 다음 프레젠테이션의 구조를 어떻게 짤지 고민될 때. 빠른 입력을 열고, 음성 모드로 전환해 생각을 쭉 이야기하세요. Claude가 여러분이 한 말을 바탕으로 개요 초안을 작성해 줍니다.
- 몇 주 동안 Apple Notes 앱 여기저기에 제품 출시 관련 아이디어를 적어두었을 때. 설정에서 메모 커넥터를 추가하고 Claude에게 "Osprey 출시와 관련해서 내 메모에 있는 모든 내용을 취합해 줘. 그리고 어디서 쓰다 말았는지 파악하고, 다른 연결된 도구들을 확인해서 빈틈을 채워줄 내용이 있는지 찾아봐 줘."라고 요청해 보세요. Claude는 로컬 기기의 메모를 읽고, 보유한 자료들을 모아 작성하다 만 부분부터 이어서 작성해 줍니다.

## Cowork

![__wf_reserved_inherit](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/69a8c30634a6c3e54526979c_69a8a456caa28723041a6ee7_699e2c4828218e71872531df_699e289b7bffb76b5ebedc79_Screenshot%252525202026-02-24%25252520at%252525202.39.06%252525E2%25252580%252525AFPM.png)

Claude Cowork는 여러 소스에서 정보를 가져와 의미를 파악하고 완성된 결과물을 만들어내는 등, 상당한 공수가 들어가는 작업을 위해 설계되었습니다.

Claude는 프로젝트의 여러 부분을 동시에 다루는 멀티태스킹이 가능하여 더 많은 자료를 검토할 수 있는 여유와 끝까지 해내는 지구력을 가지고 있습니다. 철저한 리서치 브리프, 여러 출처를 교차 검증하는 재무 분석, 처음부터 끝까지 살펴보는 계약서 리뷰, 흩어진 자료들을 모아 세련되게 다듬은 슬라이드 덱 등이 가능합니다.

작업을 시작하기 전, Claude는 종종 범위를 한정하거나, 형식, 제약 조건 등 여러분에게 필요한 것을 파악하기 위해 몇 가지 짧은 질문을 던집니다. 이후 사이드바에서 검토할 수 있는 계획을 수립합니다. 작업이 진행되는 동안, 참조하고 있는 소스, 형태를 갖춰가는 파일들, 계획 대비 진행률 등 과제가 구체화되는 과정을 지켜볼 수 있습니다. 각기 다른 대화창에서 여러 작업을 동시에 실행시킬 수 있으며 사이드바에서 쉽게 전환할 수 있습니다.

- **폴더 접근 권한 (Folder access).** 컴퓨터의 특정 폴더를 지정해 주면 Claude가 그 안의 내용을 읽고 관련된 것을 파악한 후, 끝마친 작업 결과물을 같은 폴더에 바로 저장합니다. 파일을 업로드하거나 대화창에 내용을 복사해 붙여넣거나, Claude에 필요한 내용을 가져오는 도구를 연결할 수도 있습니다.
- **예약된 작업 (Scheduled tasks).** Claude는 예약된 일정에 따라 반복적인 작업을 처리할 수 있습니다. Slack과 캘린더를 요약한 일일 브리핑, 배포 완료된 사항에 대한 주간 요약 보고서, 아침마다 확인이 필요한 이메일 분류 등이 가능합니다. 작업 내용과 실행 시점을 정의해 두면 데스크톱 앱이 열려있을 때마다 Claude가 알아서 처리합니다. 작업 예정 시간에 컴퓨터나 앱이 꺼져 있었다면 다시 켜졌을 때 밀린 작업을 수행합니다.
- **브라우저 사용 (Browser use).** Chrome용 Claude를 연결하면, Claude가 직접 웹사이트를 탐색하고 페이지와 상호 작용하며, 찾은 정보를 작업 중인 태스크로 바로 가져올 수 있습니다. 이를 통해 10개 경쟁사 사이트를 돌아다니며 가격을 비교하거나, API가 없는 페이지에서 데이터를 수집하는 등의 일을 Cowork에서 수행할 수 있습니다.
- **플러그인 (Plugins).** 플러그인은 실시간 재무 데이터 가져오기, 사내 지식 기반 스토리지 검색, 특정한 컴플라이언스 프레임워크 내에서 작업하기 등 Claude가 기본적으로 할 수 없는 기능들을 부여해 줍니다. Cowork 인터페이스에서 작업에 맞는 플러그인을 찾아 추가해 보세요.
- **보호된 환경 (Protected environment).** Cowork는 컴퓨터 내 독립된 공간에서 실행됩니다. 공유된 폴더 내에서는 파일을 읽고, 생성하고, 수정할 수 있지만, 그 외 영역에는 접근할 수 없습니다.

**이럴 때 사용해 보세요:**

- 데이터베이스를 쿼리하듯 사용 중인 모든 도구에서 검색하고 싶을 때. "지난 분기에 가격 정책에 대해 우리가 뭐라고 결정했더라?"라고 물어보세요. Cowork가 회의록, 프레젠테이션 자료, 이메일, 슬랙 스레드를 모조리 뒤져 답을 찾아냅니다.
- 새로운 시장을 조사하고 경쟁사를 파악하며 도구들을 평가할 때. 추출하기 힘든 정보를 찾기 위해 탭을 수십 개 띄워야 하는 리서치라면, 브라우저 탭을 하나도 열지 않고도 Cowork가 알아서 사이트들을 방문해 보고서를 읽고, 가격 정보를 추출한 뒤, 출처까지 포함된 구조화된 리서치 브리프를 전달해 줍니다.
- 세부 내용이 중요한 방대한 문서(계약서, 재무 보고서, 회의록 등)를 분석해야 할 때. Cowork는 모든 페이지를 꼼꼼히 읽고, 전체 문서 풀을 교차 참조하여 직접 모두 읽지 않고서는 발견하기 힘든 핵심 패턴을 뽑아냅니다. 50개의 문서를 마치 5개 리뷰하듯 빠르게 검토할 수 있습니다.
- 매일 아침마다 메시지 확인, 진행 상황 취합, 예정된 회의 준비 등 똑같이 반복하는 일이 있을 때. 한 번 예약된 작업으로 설정해 두면 Claude가 알아서 반복 실행해 줍니다. 귀찮은 관리 업무 대신 준비된 답안과 함께 상쾌한 하루를 시작하세요.

Cowork는 현재 리서치 프리뷰 단계로, Pro, Max, Team, Enterprise 사용자에게 제공되며, 정기적으로 새로운 기능이 추가되고 있습니다.

## Code

![__wf_reserved_inherit](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/69a8c30634a6c3e545269794_69a8a455caa28723041a6ee1_699e1b736d83c9fb55a56d2a_698be3342261cf694fdae301_698bdd78a6031117e6bb41d6_Screenshot%25252525202026-02-09%2525252520at%252525252012.52.07%25252525E2%2525252580%25252525AFPM.png)

Code 기능은 Claude Code를 바탕으로 데스크톱 앱 안에 온전한 개발 환경을 제공합니다.

Claude가 코드베이스에 직접 들어가서 코드를 읽고, 작성 및 수정하며, 명령어를 실행합니다. 어떤 부분이 시각적으로 어떻게 바뀌었는지 보여주는 visual diffs, 명령어가 실행되는 모습을 보여주는 내장 터미널을 제공하며, git이 모든 버전을 추적하므로 언제든 코드를 롤백할 수 있습니다.

Cowork가 지정한 폴더에만 접근 가능한 제한된 환경에서 실행된다면, Code 기능은 파일 시스템, 터미널 기능, 개발 도구들에 전체 접근 권한을 가지고 여러분의 프로젝트 환경 내에서 직접 실행됩니다.

작업이 진행될 환경을 선택할 수 있습니다:

- **로컬 (Local):** 내 컴퓨터의 폴더를 선택하면 Claude가 해당 파일들과 직접 작업합니다. 기기에서 실행되므로 프로젝트를 읽고, 로컬 도구에 접근하며, 개발 서버를 실행해 브라우저에서 미리 확인할 수 있습니다.
- **원격 (Remote):** GitHub 리포지토리를 연결하면 클라우드 환경에서 Claude가 작업합니다. 앱을 종료해도 세션이 계속 진행되므로 대규모 리팩토링 작업을 맡겨두고 나중에 확인할 수 있습니다. 큰 코드베이스를 다루거나 로컬 기기에 영향을 주지 않고 개발을 진행할 때 좋습니다.

세 가지 상호작용 모드를 통해 Claude의 자율성을 제어할 수 있습니다:

- **질문 (Ask):** Claude가 모든 변경 사항을 제안하고 여러분의 승인을 기다립니다. 수정이 반영되기 전에 시각화된 diff 화면을 검토하고 수락 혹은 거절할 수 있습니다.
- **코드 (Code):** Claude가 자동으로 코드를 수정하여 파일에 반영하지만, 터미널 명령어를 실행하기 전에는 승인을 구합니다.
- **계획 (Plan):** Claude가 내용을 무언가 건드리기 전에 먼저 전체적인 접근 방식을 짭니다. 전용 계획 뷰어(plan viewer)가 따로 있어 작업이 진행되는 동안 전략을 계속 검토하고 수정할 수 있습니다.

아울러 프로젝트 전반에 걸쳐 한 번에 여러 세션을 실행할 수 있으며, 사이드바에서 상태(활성화 혹은 보관됨)와 환경(로컬 혹은 클라우드) 기준으로 세션을 필터링할 수 있습니다.

Code 기능 탭은 Pro, Max, Team, Enterprise 사용자를 대상으로 순차적으로 제공되고 있습니다.

## 3가지 모드 비교하기

| | Chat (채팅) | Cowork (협업) | Code (코드) |
|---|---|---|---|
