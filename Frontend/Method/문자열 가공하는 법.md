# 문자열 가공하는 법

```typescript
"2026-02-25 16:43" 형식을 26.02.26 형식으로 만들어보자.

우리가 필요한건, 년도, 월, 일 

JS에서는 문자열을 특정 구분자로 나눌 때 사용되는 메서드가 있다. 
substring("")이랑 split("")이다. 
//substring은 음수 지원 x, split은 음수 지원 o

split은 구분자를 기준으로 배열을 나눠준다. 여기서는 "-"가 구분자이기 때문에 아래와 같은 배열이 완성된다.

=> ["2026", "02", "25 16:43"]


  이제 이 배열에서 26.02.25를 만들려면:                                                                   
  - "2026" → 뒤 두 자리만 → 
  - "02" → 그대로 사용
  - "25 16:43" → 앞 두 자리만 필요
    

"2026".slice(1, 2)를 하게 되면 결과가 어떻게 될까.
slice는 index의(시작, 끝)을 가져온다.

2026의 인덱스는 다음과 같다.
0123
=> 2=0, 0=1, 2=2, 6=3 
그러니 slice(1, 2)는 "0"를 가져오게 된다. 끝은 "직전"이라는 뜻으로 끝자리의 인덱스 앞에까지만 가져온다. 
그리고 slice(2)를 적게 되면 index의 시작부터 끝까지 가져온다는 뜻으로 "26"을 가져오게 된다. 



자 이제 필요한 메서드는 배웠다. 
다음은 구조분해할당이다.

let [year, month, day] = "2026-02-25 16:43".split("-")   

잘 나뉘어진 배열을 순서대로 변수로 나눠가진다.
결과값이 어떻게 될까?

year = "26"
month = "02"
day = "25 16:43"


이제 한 곳에 모아서 데이터를 쓰면 끝

const formattedDate = `${year.slice(2)}.${month}.${day.slice(0, 2)}`;
```
